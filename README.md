# LocAI

Qwen3 8B на этом компьютере. Пока Windows включена, чат открывается с телефона и других компьютеров в той же Wi-Fi. В интернет модель не выставляется.

## Что стоит на машине

- Ryzen 9 9950X3D, 96 ГБ памяти, GeForce RTX 5070 Ti 16 ГБ
- Модель: Huihui Qwen3 8B Abliterated v2, квант Q8. Это Qwen3 8B со снятыми отказами, файл около 8.7 ГБ
- Полная FP16 весит 16 ГБ и не помещается в видеокарту вместе с рабочим столом
- Контекст ограничен 8192 токенами, в видеокарте держится одна модель. Так карте хватает памяти ещё и на обычную работу
- Веса лежат в `models/` на диске E:. На E: свободно около 165 ГБ, отдельно место освобождать не нужно

Модель после запуска остаётся в видеопамяти, чтобы первый вопрос не ждал загрузку. Это примерно 10 ГБ из 16. Перед тяжёлой программой на видеокарте её можно выгрузить:

```powershell
ollama stop home-qwen
```

Следующий вопрос загрузит её снова.

## Как открыть чат

1. Один раз выполнить `powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1`
2. На этом компьютере открыть http://127.0.0.1:8787 и создать аккаунт. Первый аккаунт — администратор
3. С телефона или другого компьютера в той же Wi-Fi открыть адрес, который скрипт напечатает в конце (сейчас это сеть `192.168.2.36`)
4. В `.env` поставить `ENABLE_SIGNUP=false` и выполнить `docker compose up -d`, чтобы новые аккаунты больше не создавались

Ollama слушает только этот компьютер. В сеть открыт сайт, и у него есть пароль.

В чате выбрана модель `home-qwen`. Сырой тег `qwen3:8b-q8_0` лучше не выбирать: у него длинный контекст, и он может забить видеокарту.

## Сменить или обновить модель

Повторное скачивание того же тега подтягивает свежий файл, если он появился у Ollama:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-model.ps1
```

Другая модель, например более быстрый квант Q4:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-model.ps1 -Base qwen3:8b
```

Скрипт скачивает веса, заново собирает ярлык `home-qwen` и прогревает его. Имя в чате не меняется.

Обновить сам сайт:

```powershell
docker compose pull
docker compose up -d
```

## Значок в трее

Правый клик по значку LocAI у часов:

- **Приостановить** выключает модель и освобождает видеокарту. После перезагрузки она сама не поднимется, пока не нажать **Продолжить**.
- **Настройки** меняют файл модели, длину контекста и порт сайта. Новый файл должен уже лежать в `models`. Скрипт его не скачивает.

На рабочем столе лежит ярлык LocAI. При включении компьютера модель сама не стартует. Откройте ярлык, когда она нужна.

## Три способа пользоваться

Браузер уже работает. Это основной способ: компьютер, телефон, планшет. На Android сайт можно добавить на главный экран через меню Chrome «На главный экран». Отдельное приложение для этого не нужно: оно было бы окном вокруг того же сайта.

Готовое Android-приложение имеет смысл, только если хочется уведомления или офлайн-историю. Тогда в настройках сайта выпускается API-ключ, а приложение ходит в OpenAI-совместимый адрес `http://<этот-компьютер>:8787/api`. Своё приложение с нуля здесь не собирается.

Telegram-бот лежит в `telegram/bot.py` и по умолчанию выключен. Он удобен вне дома: пока этот компьютер включен, бот сам связывается с Telegram, порт наружу открывать не надо.

1. В @BotFather команда `/newbot`, токен вставить в `.env` как `TELEGRAM_BOT_TOKEN`
2. Свой числовой id взять у @userinfobot и вписать в `TELEGRAM_ALLOWED_IDS`. Чужие id бот не обслуживает
3. Запустить `scripts\start.ps1`

Команда `/reset` в чате с ботом начинает диалог заново.
